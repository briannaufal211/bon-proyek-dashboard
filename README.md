# Bon Proyek — Director Dashboard

Read-only dashboard frontend for management, published with GitHub Pages. Data is fetched from a separately deployed, access-code-protected gateway.

This repository contains presentation code only. It includes no transactions, receipts, Google service account keys, server secrets, or access codes.

The gateway must be configured and tested before the dashboard can display live information. Local receipt OCR and source data maintenance are handled by the operator separately.
