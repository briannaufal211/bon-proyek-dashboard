Bon Proyek online operator. Browser OCR: Tesseract.js v6.0.1 (https://github.com/naptha/tesseract.js), engine/model downloads occur from pinned/versioned public assets. Photo OCR is local to the browser; only confirmed JPEG receipts are sent to the protected Supabase bon-operator gateway, then appended to the private Google Sheet. No server credentials or transaction records are in this frontend.
This upload app deliberately shares the dashboard access code at the owner's request; anyone with that code can add invoices. Python PP-OCRv5 remains available in the separate local application and is not hosted by GitHub Pages.
The bundled redacted public sample is CORD v2 train sample 4, annotated total IDR 48,000 (https://github.com/clovaai/cord). OCR output must be reviewed; the expected amount is not hardcoded into the parser.
